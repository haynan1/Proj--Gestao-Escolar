Baixar dump SQL
1
Onde colocar o arquivo

Pode ficar em qualquer pasta. Para facilitar, salve o arquivo baixado na raiz deste projeto ou use a pasta padrao de downloads: C:\Users\HAYNAN\Downloads.

2
Importar pelo PowerShell

Entre na pasta onde o arquivo foi salvo e rode o comando abaixo.

cd "$env:USERPROFILE\Downloads" cmd /c "mysql -u root -p nome_do_banco < flowter_dump.sql"
3
Nome do banco local

Troque nome_do_banco pelo valor do seu DB_NAME no arquivo .env. Se usar o exemplo do projeto, o nome e gestao_escolar.
